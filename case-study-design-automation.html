Overview


At Lowe's India, our marketing and advertising production squads were spending a massive 45% of their weekly capacity manually resizing, mapping, and formatting advertising layout variations across hundreds of regional campaigns.

To resolve this operational bottleneck, I architected and built a custom Figma automation plugin. This plugin maps dynamic assets to pre-approved layout templates, handles intelligent scaling, and exports multi-aspect ratios automatically.

The Challenge

With 5 product teams designing for hundreds of distinct retail promotions, designers were stuck in a loop of copy-pasting, manually resizing frames, and checking asset compliance rules. This manual workflow introduced consistent layout and typography specification errors, slowed sprint velocity, and created design-to-development handoff delays.

The core goal was to build an automated, single-click solution that integrated into designers' daily Figma workspace without disrupting their standard workflow.

The Solution

I developed a custom Figma automation plugin built with the Figma Plugin API and HTML/CSS UI panels. The plugin features:

Asset-to-template Mapping: Automates data mapping via node metadata and Figma components.

Responsive Autolayout scaling: Leverages Figma's native Autolayout structures to scale text and imagery fluidly across aspect ratios.

One-click compliance QA: Validates contrast and specifications instantly before export.

The Result


45% Time Saved

Eliminated manual resizing workflows, letting designers focus on creative campaign discovery.

Zero Handoff Errors

Automation locked templates to design specifications, ensuring 100% compliance.

3x Faster Handoff

Handoff files generated automatically, optimizing delivery speed across Agile sprint cycles.
